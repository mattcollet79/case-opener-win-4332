## Overview

Case-opener is a browser-based HTML game centered on case opening gameplay. It is designed around a Counter Strike-style presentation, with the main interaction focused on opening cases and watching the outcome unfold in the web interface.

The project emphasizes simple gameplay tuning through speed and friction controls. Those settings let you adjust how the case-opening motion feels during play, making the experience easier to tailor to different preferences while keeping the implementation lightweight and web-friendly.
